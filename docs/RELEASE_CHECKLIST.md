# SPlite 发布检查清单

## 构建与质量

- 使用干净工作区编译 `x64 Release`。
- 运行 `SPlite.Tests.exe`，确认全部测试通过。
- 在集成显卡和独立显卡上各运行至少 30 分钟。
- 检查待机、拖动、多角色、显示缩放和多显示器行为。
- 检查 `%TEMP%/SPlite_renderer.log` 中没有初始化或 Present 错误。
- 当前 MSVC 14.51 偶发误解析中文 BOM 源码；发布脚本会增量重试，CI 使用 v143 复核。

## 许可与素材

- 确认 Spine Editor 与 spine-cpp Runtime 版本一致。
- 保存集成 Spine Runtime 时有效许可证的购买记录。
- 确认角色、音乐、字体和图标拥有商业发行及宣传用途授权。
- 在第三方声明中附带所有依赖要求的许可证文本。

## Steam

- 使用真实 App ID 验证初始化、Overlay、成就和云存档。
- 在 Steamworks 后台完成商店页、隐私信息、内容问卷和定价。
- 使用独立测试分支验证 depot，不直接覆盖默认公开分支。
- 检查安装、升级、卸载和无网络启动流程。
- 上传符号文件到私有崩溃分析存储，不随公开构建分发完整 PDB。
