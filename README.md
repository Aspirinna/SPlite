# SPlite

一个面向 Windows 的商业级桌面宠物（Pet-on-Desktop）项目。

## 技术栈

- C++20
- Win32 / DirectX
- Spine Runtime（计划集成）
- Steamworks（计划集成）

## 当前状态

项目处于起步阶段，当前是一个可编译的 Win32 桌面应用骨架。

## 构建

使用 Visual Studio 打开 `SPlite.slnx`，选择 `x64` + `Debug` 配置编译即可。

## 目录结构

```
src/      C++ 源码
res/      资源文件（图标、资源脚本等）
assets/   运行时素材（后续添加）
docs/     项目文档（后续添加）
```
